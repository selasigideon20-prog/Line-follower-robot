# Mercedes-Benz Auto Robot

## Projectbeschrijving

Dit project werd ontwikkeld voor Mercedes-Benz. Het doel is een autonome robotwagen die een lijn volgt, obstakels detecteert en gegevens verstuurt via MQTT.

---

## Functionaliteiten

* Lijnvolging
* Obstakeldetectie
* Stop- en hervatfunctie via drukknop
* MQTT-communicatie
* Batterijmonitoring
* Dashboard voor monitoring
* I2C-communicatie

---

## 🛠️ Hardware Componenten

* ESP32
* TCRT5000 IR Sensor Array
* XL6009 Buck-Boost Converter
* TB6612FNG / L298N Motor Driver
* DC Motoren
* Drukknop
* LEDs
* Batterij
